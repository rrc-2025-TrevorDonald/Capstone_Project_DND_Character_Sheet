# Back-End Development Capstone Project

Author: Trevor Donald

## Learning Outcome

In this capstone project, you'll build a complete back-end application that pulls
together all the core skills we've practiced in this course. You'll also extend your
project by researching and adding a new back-end feature of your choice, showing you
can apply what you've learned while exploring something new. The project is structured
into three main milestones, giving you a chance to present your progress in Week 3 with
a sprint demo. This is your opportunity to show a working back-end app that's secure,
tested, and well-documented—and to wrap it up with a feature you've chosen and implemented
yourself.

## Description

I created a Dungeons and Dragons character and campaign manager site, that allows you to create an account
and create as many characters as you want. All characters you create are only available to you and your
Dungeon Master (DM). DM's are also able to create campaigns, manage the players in the respective campaigns,
create notes for their campaigns and view all characters created.
